# Benchmarks register

This file is the single register of every number the topic files use. Open it before stating a statistic to get the exact value, source, date, sample and caveat, and quote the row ID in the self-report line when useful.
Vendor datasets (Gong, JOLT/Dixon, Bridge Group, Belkins, Lavender, RAIN, 6sense, Gartner, Forrester, Edelman, Huthwaite) are correlational and self-selected; say so, in a few words, every time one is quoted.
A number is quoted with its sample and year or not at all. A row whose link reads "no URL in notes layer" may be used only as "<Name> reports…", or cut.
If a topic file and this register disagree, this register wins, and the topic file is a bug to name in the deliverable's self-report line.
Tags follow AUTHORING.md: [study], [data], [practitioner], [opinion], plus replication flags where relevant. Caveat cells are deliberately terse; the notes layer (outside this repo) holds the detail.
ID prefixes: D discovery and rapport; O objections and closing; N negotiation and pricing; P outreach, prospecting and personal branding; F offer, positioning and pitching; R persuasion research; S sales process, hiring, coaching, compensation; M mindset; B buyer-side. IDs are stable: append, never renumber.
